## Why we pruned

1. Managers need prompts and clear rules, not a monorepo of apps.  
2. Mixed signals (“is the product a dashboard or a library?”) slowed adoption.  
3. Maintenance cost of multi-runtime CI distracted from literacy outcomes.  
4. SharePoint + Gemini Enterprise are the delivery surfaces that match current access.

## If someone asks for the old demos

Point them to the legacy repo README and treat demos as **optional show-and-tell**, not onboarding.

## Rule going forward

New work lands here **only if** it helps managers use AI safely:

- New prompt or category  
- New or improved soul  
- Playbook update for SharePoint / Power Automate / GCP / Gemini  
- Governance clarity  

Net-new apps require a pilot proposal and must not re-take the README headline.
