# Plain-English Glossary

| Term | Meaning here |
| --- | --- |
| **Prompt** | Instructions you paste into AI so it knows what you want |
| **Agent** | A saved AI helper with fixed instructions (a soul) so you don’t re-explain every time |
| **Soul / soul.md** | The personality + guardrails file for an agent |
| **Draft** | AI output that a human must edit before it counts as real work product |
| **Scrub** | Remove sensitive details; replace with placeholders like `[Station A]` |
| **Placeholder** | A stand-in such as `[Customer group]` instead of a real name |
| **Needs verification** | AI is unsure or you must check a source system before acting |
| **Human in the loop** | A person reviews or approves before anything important happens |
| **Gemini Enterprise** | Company-managed Google Gemini environment (web UI for agents) |
| **SharePoint** | Where managers will browse prompts/agents day to day (when live) |
| **Power Automate** | Microsoft tool that runs workflows (notifications, approvals) |
| **Agentic workflow** | Multi-step process that may include AI **plus** routing/approvals — still needs human gates here |
| **Data classification** | How sensitive data is (public / synthetic / internal / confidential) |
| **Synthetic data** | Fake-but-realistic data for demos and tests |
| **Pilot** | Small, time-boxed test with clear success metrics |
| **GCP sandbox** | Isolated Google Cloud project for engineering experiments |
| **Agency ladder** | Levels from “draft only” up to “act autonomously” — we stay low |
| **Source of truth** | The system you trust for facts (not the chatbot) |

If a term is missing, open an issue or add it in a PR.
