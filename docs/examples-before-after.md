# Before / After Examples

Show managers what “good” looks like. All examples are synthetic.

---

## 1) Weak ask → Strong prompt

### Before (weak)

```text
Make a shift update.
```

### After (strong)

```text
Goal: Write a night-shift handoff for the incoming supervisor.
Context: Station A, rain after 02:00, one belt late from maintenance.
Source: Use only the scrubbed notes below.
Rules: Do not invent facts. Put gaps under Needs verification.
Output: What changed · Still open · Risks · Owners (roles) · First checks · Safety line

Notes:
[paste scrubbed notes]
```

**Why better:** audience, boundaries, format, and anti-guessing.

---

## 2) Risky paste → Safe paste

### Before (risky)

```text
Customer Jane Doe at 123 Main St tracking 7946… is mad. Driver Bob was late…
```

### After (safe)

```text
Customer group: [Residential pickup complaint]
Issue category: [Late delivery perception]
Service notes: [Window missed per customer; cause unverified]
Driver/employee details: [Do not include — handle in approved HR/ops systems]
```

**Why better:** same problem structure, no PII.

## 3) Bad AI habit → Good manager habit

| Bad | Good |
| --- | --- |
| Send AI email as-is | Edit, then send |
| “AI said root cause is staffing” | “Hypothesis — verify with data owner” |
| Paste full scorecard export | Paste aggregates or screenshots scrubbed of IDs |
| 12 half-built agents | 3 solid agents with souls |

## 4) What a solid brief draft looks like (illustrative)

```text
DRAFT — needs manager verification

Priorities
1. Confirm belt return time with maintenance (role: sort lead)
2. Verify feeder ETA in system (role: linehaul coord)
3. Wet-dock awareness at doors after 02:00
4. Overflow lot control and walk-path safety
5. QA misload focus — extra checks first two hours

Risks
- Rain / wet plates
- Compressed outbound if feeder later than estimated
- Equipment catch-up if belt returns late

Needs verification
- Feeder “~30 min late” — confirm in system before briefing network partners

Safety
Wet floors at dock doors. Three points of contact. Safety Above All.

Owners/next steps
- Sort lead: belt status at start + top of hour
- Supervisor floater: overflow lot + wet-area checks
- QA: misload sampling plan for first two hours
```

Notice: roles, verification, no invented package counts.
