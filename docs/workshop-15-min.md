# 15-Minute Manager Workshop

**Audience:** 5–20 Operations Managers  
**Materials:** Wallet card, Prompt Explorer, Gemini Enterprise access, demos folder  
**Outcome:** Each person has run one prompt and knows the safe-use rule  

---

## Agenda

| Min | Activity | Owner |
| --- | --- | --- |
| 0–2 | Why this exists + **AI drafts / you decide** | Facilitator |
| 2–4 | Safe use: never paste list (wallet card) | Facilitator |
| 4–5 | Open Prompt Explorer (`prompts/explorer.html`) | Everyone |
| 5–9 | Hands-on: copy **P01** or run [demo 01](../demos/01-shift-brief.md) | Everyone |
| 9–11 | Peer check: “What would you edit before sending?” | Pairs |
| 11–13 | Optional: P08 safety huddle speed round | Everyone |
| 13–15 | First-week homework + feedback path | Facilitator |

---

## Facilitator talking points

- This is **not** a bot that runs the building.  
- Best first uses: briefs, handoffs, huddles, meeting actions, metric questions.  
- If it invents a number, that is a **bug in use** — verify or delete.  
- SharePoint will be the front door later; Explorer works today offline.  

## Homework (one week)

1. Use **two** prompts from: P01 · P02 · P08 · P15 · P20 · P44  
2. Estimate minutes saved  
3. Reply with one invented-fact near miss (or “none”)  

## Exit ticket (optional form)

- I used prompt: ___  
- Minutes saved: ___  
- I would recommend to a peer: Y/N  

## If Gemini is down

Print/PDF the wallet card + one prompt from CATALOG and run the workshop as “write the prompt for later.”  
Do not invent a shadow tool.
