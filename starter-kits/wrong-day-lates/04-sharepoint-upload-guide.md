# 04 — SharePoint Upload Guide

**Goal:** Publish this starter kit on the AI Efficiency Group SharePoint page so every manager can find it without GitHub fluency.

---

## Steps

1. Open the team SharePoint page (use sharepoint/ops-ai-library-page-template.html as the base if the page doesn't exist yet).
2. Add a new section titled **Wrong-Day / Right-Day Lates Starter Kit**.
3. Upload or link these five files from starter-kits/wrong-day-lates/:
   - README.md (as the section intro)
   - 01-gemini-enterprise-pack.md
   - 02-power-automate-flow-d.md
   - 03-correlation-matrix-framework.md
   - 04-sharepoint-upload-guide.md (this file — optional on the page)
   - 05-measurement-plan.md
4. Add the P45–P48 prompts (from prompts/late-arrival-and-service-recovery.md) as copy-ready cards in the same section.
5. Add the Data Cards (governance/data-cards.md) as a linked reference.
6. Confirm with governance that the page uses approved enterprise links only — no public GitHub URLs if policy forbids them on internal pages.

## What to tell managers in one sentence

> "This kit gives you a Gemini Enterprise agent that drafts late-arrival briefs from approved sources — evidence first, draft only, you decide. Start with a synthetic example before any real report."

## After upload

- Announce in Teams using the teams-announcement.md pattern.
- Start the pilot scorecard (docs/pilot-scorecard.md) for the first 30 days.
- Feed measured results back to this repo as a dated note under docs/.
