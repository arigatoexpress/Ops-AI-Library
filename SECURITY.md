# Security

## Reporting

If you find sensitive data that should not be in this repository, contact the repository maintainers immediately and open a private report if available.

## Rules for this repo

- No secrets, API keys, tokens, or passwords.  
- No real tracking numbers, customer PII, employee records, or route manifests.  
- No real employee names, corporate email addresses, portal URLs, browser session files, or internal source exports in demos or fixtures.
- No security procedures that would help an attacker.  
- Treat all examples as synthetic or scrubbed.

Use reserved `.invalid` email addresses for public fixtures. Generated compliance data and draft output must remain ignored and local.

If sensitive data was committed, removing it from the latest file is not the same as removing it from Git history. Notify the maintainer privately so a scoped history-remediation decision can be made.

## AI-specific

Prompts and souls in this library are designed for **approved enterprise tools**.  
Using them in personal / public AI tools with confidential company data is not allowed.
