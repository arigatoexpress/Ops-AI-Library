## Weekly pulse (5 questions)

Ask pilots every Friday (Teams form is fine):

1. Did you use a prompt or agent this week? (Y/N)  
2. Minutes saved (estimate): ___  
3. What did you use it for?  
4. What did you have to fix?  
5. Any invented facts or unsafe suggestions? (Y/N + note)
