# Manager Wallet Card

**Print this. Fold it. Keep it near your keyboard.**

---

## The rule

> **AI drafts. You decide.**  
> Never paste tracking #s, customer names, employee records, routes, or passwords.

---

## 60-second path

1. Scrub notes → use `[Station A]`, `[Shift 2]`, `[Issue category]`  
2. Open Gemini Enterprise (or your approved tool)  
3. Paste a prompt from the Ops AI Library  
4. Edit the draft → then share  

---

## When to use which prompt

| I need… | Use |
| --- | --- |
| Start of shift | Daily Manager Brief |
| Leaving for next shift | Shift Handoff |
| 2-minute safety talk | Pre-Shift Safety Huddle |
| Boss wants a short update | Executive Update |
| Numbers look weird | Metrics Interpretation |
| Meeting notes → owners | Notes To Action Items |
| Is this AI idea safe? | “Is This Safe To Try?” |

---

## Good output looks like

- Short and usable  
- **Needs verification** on anything fuzzy  
- Roles as owners (not guessing names)  
- Safety line on ops briefs  
- No invented counts or root causes  

---

## Stop and scrub if you see

Tracking numbers · addresses · phones · employee performance · signatures · GPS · credentials

---
